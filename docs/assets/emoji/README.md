# Twemoji SVG assets

These SVG files are the Twemoji artwork used for the robot's daily/weather
stickers.

- Source: <https://github.com/jdecked/twemoji> (via the `@twemoji/svg` npm package)
- License: [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Attribution: "Emoji artwork: Twemoji (CC-BY 4.0)" is shown in the panel footer.

Files are named by Unicode codepoint, e.g. `1f9e2.svg` = 🧢.
